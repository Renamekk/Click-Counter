# Changelog

## v1.0.0 - 2026-10-15

### Русский

Первый релиз Click Counter для Android 8.0+.

- Один экран с четырьмя механическими барабанами.
- Кнопки +, -, RESET и диапазон 0000-9999.
- Анимация цифр, объёмные кнопки и тактильный отклик.
- Сохранение текущего значения на устройстве.
- Работа без интернета, рекламы, аккаунтов и истории.
- APK подписан ключом приложения. Рядом опубликована SHA-256.

### English

First release of Click Counter for Android 8.0+.

- One screen with four mechanical number drums.
- +, -, RESET controls and a 0000-9999 range.
- Animated digits, tactile buttons and haptic feedback.
- The current value is saved on the device.
- Offline operation with no ads, accounts or history.
- The APK is signed with the app key. A SHA-256 checksum is included.
